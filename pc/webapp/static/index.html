How it works here

Live failover test reversible, no cable pulling

Shut Gi 1/2 and watch the FRER table: Passed keeps climbing at the same rate while Discarded stops — there is simply no second copy left to throw away. Lost stays at 0.

Never shut Gi 1/1. It is the only link carrying switch2's management VLAN — shutting it makes switch2 unreachable and needs a physical reboot. Gi 1/2 carries the FRER VLAN only, so it is the safe one to cut.

CSI Radar

the three boards' radio paths, used as a direction-of-motion sensor

Paths thicker = more channel disturbance right now

Each edge is a real radio path between two boards, and its thickness is that path's CSI amplitude variance — how much the channel is wobbling. A body in a path's Fresnel zone changes the multipath and the edge thickens.

What this is not

There is no range axis here, and the picture deliberately draws none. Range resolution is c/2B, and B is one 20 MHz WiFi channel — 7.5 m, so a room is a single range bin. Angle of arrival is out too: one antenna per board and three independent clocks, so there is no phase coherence to beamform with. Direction here comes from which path is disturbed, nothing more. Real range and bearing need bandwidth or an array — UWB (500 MHz, ~30 cm) or 60 GHz mmWave.
